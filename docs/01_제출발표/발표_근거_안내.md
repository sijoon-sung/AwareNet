## 자료의 역할

| 위치 | 역할 | 관리 기준 |
|---|---|---|
| `sfl/` | 실제 실행 코드 | 모델·계획·전송·SDN 모듈을 구분 |
| `scripts/analysis/` | 재현 및 분석 실행기 | 실행 조건과 결과 폴더를 명시 |
| `configs/`, `scripts/exp/conditions.json` | 기존 실험 조건과 근거 | 측정값·가정·장비 제약을 구분 |
| `out/followup_20261001/` | 이번 추가 실험 | 실행별 manifest, 원로그, 예측 결과, 모델 저장 |
| `docs/02_실험/` | 조건·결과·판정 | 좋은 결과와 차이가 없는 결과를 함께 기록 |
| `docs/04_설계기록/` | 설계 변경의 이유 | 과거 제안은 현재 구현과 구분 |
| `site/` | 승인된 공개 자료 | 검토 중 원고·로컬 추가 결과와 구분 |

큰 모델 파일과 원본 데이터는 Git에 직접 추가하지 않는다. 공개할 때는 조건·경량 로그·집계표·재현 명령을 포함하고, 모델은 별도 다운로드 또는 재현 경로로 연결한다.

## 발표에서 구분할 실험

- **KOREN 기존 측정:** 실제 원격 전송과 학습. 기존 24/200라운드 결과.
- **Fashion-MNIST 추가 학습:** 로컬에서 실제 모델 학습·집계. 네트워크 제어 성능을 측정한 실행은 아니다.
- **동일 연결 수 TCP 진단:** 실제 로컬 소켓에 합성 연산 지연과 응용 계층 속도 제한을 적용. 정책 판단을 확인하는 보조 실험.
- **LoRA:** 분할·연합 학습과 별도의 경로 제어 기록. 랭크 선택 구현과 런타임 동적 랭크 실증을 구분.
- **Jetson:** 장치 단독 Qwen-LoRA 연산·전력 측정.

## 재현

저장소 루트에서 다음을 실행한다. 같은 출력 경로를 재사용하면 기존 결과 보호를 위해 중단한다.

```powershell
.venv/Scripts/python.exe scripts/analysis/fashion_followup.py --rounds 100 --out out/reproduction/fashion_100r
.venv/Scripts/python.exe scripts/analysis/equal_connection_probe.py --out out/reproduction/equal_connections
```

Fashion-MNIST는 첫 실행 시 공식 저장소에서 다운로드한다. 실제 실행에 사용한 패키지 버전·장치·코드 해시는 manifest에 기록한다. 체크포인트는 라운드 고정 종료 후 전역 모델이며, 최종 시험셋으로 체크포인트를 선택하지 않는다.
