# AwareNet 실험 종합 보고 (2026-09-08 20:30 기준, 실험 3 전 조건 완료)

**결론.** 라운드를 10초 안에 끝내라는 목표를 주면, 모델만 줄이는 방식은 8대 중 대부분을 절반 크기로 만들어야 하고 정확도가 8점 떨어진다.
엣지 바꾸기와 두 회선 나눠 보내기를 먼저 쓰면 계산이 느린 1~2대만 줄이면 되고 정확도는 그대로다. 스케줄러가 이 판단을 기기마다 자동으로 한다.

## 1. 무엇을 만들었나
분할 연합학습(기기가 앞부분, 엣지 서버가 뒷부분). 라운드가 긴 이유는 기기마다 다르다(계산 느림 / 회선 약함 / 엣지에 몰림). 스케줄러 손잡이 4개:
모델 폭 줄이기(계산 느린 기기에만, 정확도 대가) · 엣지 바꾸기(SDN 경로 변경) · 두 회선 나눠 보내기(조각 전송·재조립) · 즉시 내보내기(배치 4조각, 계산·전송 겹침).
리그: HPC 기기 8대 → KOREN → VM 2대(엣지 4개) → HPC 서버. 회선·엣지 용량은 tc, 자가 검사 통과. 100대는 8대 실측으로 보정한 시뮬.

## 2. 실험 1 — 모델 폭: 효과와 대가
- 망 넉넉·속도만 다른 4대: 느린 기기 폭만 줄여 라운드 −26%, 나머지 폭 1.0 유지 (h5c).
- 전원 같은 폭 400R 3시드 정확도: 폭 0.25/0.5/0.75/1.0 = 68.4/72.9/73.7/71.0 (증강 없음), 79.9/81.4/82.5/80.7 (증강). 전원 같은 폭이면 2~3점.
- 기기마다 폭이 다르면 손해가 커진다(HeteroFL·FjORD): 실험 3, 24R 에서 8대 절반 폭 17% vs 안 줄임 25~26%.
- 즉시 내보내기: 시간 −30% 추가, 그러나 조각 8장의 BN 통계 흔들림으로 정확도 하락 → m=2 또는 GroupNorm 으로 별도 해결.

## 3. 실험 2 — 망 손잡이 (8대 동질, 전원 엣지 1 시작, 16R × 2시드, 라운드 시간 Δ)
| 엣지 용량(수요 대비) | 엣지 바꾸기 | + 나눠 보내기 | 더 얹는 몫 |
|---|---|---|---|
| 넉넉 ρ0.5 | −16% | −30% | +13%p |
| 같음 ρ1 | −50% | −56% | +7%p (즉시 내보내기 시 −30% 추가) |
| 부족 ρ2 | −64% | −65% | +1%p |
100대 시뮬(실측 효율 보정): 엣지 −25/−60/−72%, 나눠 보내기 +14/+11/+0%p.

## 4. 실험 3 — 함께 썼을 때 (혼합 8대: 느린 2, 회선 약한 2, 정상 4 · D=10s · ρ1 3시드 24R)
| 방법 | 라운드 | 모델 크기 평균 | 10초 안 | 정확도 | 줄어든 기기 |
|---|---|---|---|---|---|
| 아무것도 안 함 | 19.0s | 1.00 | 0% | 25% | — |
| 모델만 (단순 분할학습) | 9.4s | 0.55 | 95% | 17% | 8대 거의 전부 |
| 망만 (엣지+나눔) | 14.5s | 1.00 | 76% | 26% | 없음, 느린 2대 미달 |
| 모델+엣지 | 9.2s | 0.82 | 95% | 23% | 느린 2 + 회선 약한 2 |
| **모델+엣지+나눔** | 9.3s | **0.93** | **100%** | **26%** | 느린 1~2대만 |
| 전부+즉시 내보내기 | 8.6s | 0.97 | 100% | 14% | 느린 1대 (정확도는 조각 문제) |
기기별: 제안 방식은 3시드 모두 회선 약한 2대를 두 가닥으로 나눠 폭 유지, 정상 4대는 엣지 분산, 폭 축소는 느린 1~2대뿐. 나눔이 없으면 회선 약한 2대까지 깎아야 했다.
대조 (2시드): ρ0.5(엣지 넉넉) 폭만 0.84·100% / 망만 1.00·88% / 결합 0.95·100% — 망이 문제가 아니면 폭만도 낙오자만 깎는다.
ρ2(엣지 부족) 폭만 0.50·0%·정확도 10% / 망만 1.00·74% / 폭+엣지 0.80·97% / 결합 0.84·98%·정확도 26% — 모델을 줄여서는 답이 없고 엣지를 바꿔야 한다.

## 5. 무선 확장
AirComp 는 해당 없음(활성값은 더하면 안 됨, TCP/IP). 무선 가닥 속도 흔들림 시뮬: 2초 주기는 이득 유지(+23→+19%p), 10초 주기 ±75% 는 절반(+9%p)이나 손해·왕복 없음. 다음 손잡이 = 관측 창 길이.

## 6. 솔직하게 적어 두는 것
- 실험 3 의 1차 실행은 무효(전송 시간 2배 계산 결함 → 전원 폭 0.5). 수정·시험 후 재실행. 1차는 out/combo_v1/.
- 정확도 시드 잡음 4~6점(GPU 비결정) → 5점 넘는 차이만 말하고 폭 대가는 문헌으로 보강.
- 내려받기 회선 상한은 리그에 없음(tc 불가) → 회선 약한 기기가 모형보다 빠름.
- 실회선 채널 효율 ≈ 1, 루프백 0.68 은 루프백 고유.
