# R(w) 예비 실험 — 학습량(폭)별 정확도 궤적과 교차 검증 (2026-09-03, HPC V100)

> 목적: 공동 최적화 정식화의 R(w)(목표 정확도 도달 라운드 수) 재료. 러너 `sfl/experiments/run_rw.py`,
> 결과 `out/hpc/rw_*.jsonl`, 그림 `out/fig/rw_curves.png`. 회수 `bash scripts/exp/hpc_fetch.sh`.

## 1. 조건

| 항목 | 값 |
|---|---|
| 모델 | ResNet-18 계열(단 폭 64·128·256·512), 절단점 cut=2, 클라이언트가 앞부분·서버가 뒷부분 |
| 폭 p | 0.25 / 0.5 / 0.75 / 1.0 — **전원 같은 폭으로 고정**(oracle-plan). 각 폭은 채널의 앞쪽 p 비율만 사용 |
| 데이터 | CIFAR-10 5만 장, 클라이언트 4대, Dirichlet α=0.5 비동일 분포. **증강 없음**(ToTensor·정규화만) |
| 학습 | SGD lr 0.05 고정, 모멘텀 0.9, 배치 32, 라운드당 40배치, 40라운드, 시드 3회. 평가는 시험 1만 장 전체 |
| 집계 | FedAvg(중첩 평균). 평가는 실제로 학습된 최대 폭으로 |
| 장비 | HPC V100 16GB, 클라 4대·서버 모두 같은 GPU |

## 2. 결과 (40라운드 판)

| 폭 | 최종 정확도 평균 ± 편차 | 40% 도달 R | 50% | 55% | 60% | 라운드당 시간 |
|---|---|---|---|---|---|---|
| 0.25 | 61.7 ± 3.6 | 9.7 | 18.0 | 25.0 | 미도달 | 1.6초 |
| 0.50 | 64.8 ± 2.3 | 8.0 | 19.7 | 23.0 | 29.0 | 2.0초 |
| 0.75 | 63.6 ± 1.9 | 9.7 | 19.3 | 24.7 | 32.0 | 2.9초 |
| 1.00 | 58.6 ± 2.8 | 10.0 | 19.7 | 26.7 | 미도달 | 3.3초 |

관측: 40라운드 안에서 폭별 궤적이 겹치고, 전체 폭(1.0)이 끝에서 가장 낮다. 시드 간 편차(2~4%p)가 폭 간
차이와 같은 크기. 라운드당 시간은 폭에 비례(1.6 → 3.3초).

## 3. 교차 검증

### 3-1. 논문(FjORD, NeurIPS 2021)은 뭐라고 하나

- Fig. 3 (비연합, CIFAR-10 전체, ResNet-18): 폭 p=0.2 → 1.0 으로 갈수록 정확도가 **단조 증가**, 약 91% → 95%.
  "SM"(폭별로 따로 학습한 독립 모델 — 우리 설정과 같음)도 같은 경향. 즉 **수렴 근처에서는 넓을수록 좋고 격차는 3~4%p**.
- Fig. 4 (연합, 100 클라이언트 IID, 500장씩): 마찬가지로 p 가 클수록 높음. 저자들이 좁은 모델이 초반에 더 빠르다는
  언급은 하지 않음.
- 학습 조건이 우리와 다르다: 그쪽은 수렴까지 충분히 학습(증강·스케줄 포함, 부록), 우리는 정확도 60%대의 **학습 초반**.

### 3-2. 폭 구현에 결함이 있나 — 대조 실험

전체 폭(1.0)을 oracle-plan 으로 고정한 것과, 폭 기능을 전혀 쓰지 않는 무개입(uniform) 정책을 같은 시드로 비교.

| | R10 | R20 | R30 | R40 |
|---|---|---|---|---|
| 무개입 uniform, 시드 1 | 44.8 | 54.2 | 61.7 | 61.6 |
| 무개입 uniform, 시드 2 | 36.0 | 53.3 | 57.8 | 63.5 |
| oracle 폭 1.0, 시드 2 | 35.2 | 44.9 | 50.9 | 54.9 |
| oracle 폭 1.0, 시드 1 | 42.9 | 52.5 | 58.3 | 61.8 |

같은 궤적이다(차이는 GPU 비결정성 수준). **폭 1.0 = 보통의 전체 모델**이고, 폭 고정 경로에 결함은 없다.

### 3-3. 그러면 왜 전체 폭이 낮게 나오나 — 학습 조건 때문

- 증강이 없고 lr 이 0.05 고정이며 40라운드는 학습 초반이다. 이 조건에서는 매개변수가 많은 전체 폭이 과적합·요동에
  더 취약하고, 좁은 폭은 용량이 작아 정칙화 효과를 얻는다 — 초반 궤적이 겹치거나 역전되는 것은 이상하지 않다.
- 논문의 "넓을수록 좋다"는 수렴 근처 이야기다. 우리 40라운드 결과로 "폭이 정확도에 영향 없다"고 말하면 안 되고,
  "학습 초반에는 폭을 줄여도 도달 라운드 수 차이가 거의 없다"까지만 말할 수 있다.

### 3-4. 추가로 돌리는 것 (HPC, nohup)

1. 폭 1.0·0.25 시드 4·5 추가 — 시드 분산 확인
2. 120라운드 × 4폭 × 시드 3 (증강 없음) — 수렴 근처에서 갈라지는지
3. 120라운드 × 4폭 × 시드 3, **증강 켬**(무작위 자르기·좌우 반전, `--augment`) — 논문 조건에 가깝게

결과는 `out/hpc/rw_40R/`(40라운드 판), `out/hpc/rw_*`(120라운드), `out/hpc/rwaug_*`(증강)로 나눠 둔다.

## 4. 정식화에 주는 뜻 (잠정)

- 학습 초반 구간에서는 R(w) 가 사실상 상수 → 학습량 축소의 라운드 수 대가가 작고, 시간 절감은 폭에 비례해 확실하다.
- R(w) 를 함수로 적합하려면 수렴 근처 데이터가 필요하다 → 3-4의 120라운드·증강 판을 기다린다.

### 5-4. 읽는 법

- 120라운드에서도 폭 4수준의 최종 정확도가 2%p 안에 모여 있고, 그 차이는 시드 편차와 같은 크기다. 증강을 켜도 마찬가지다.
  전체 폭이 가장 좋지 않다는 것은 "결함"이 아니라 이 설정(클라 4대·비동일 분포·학습률 고정·120라운드)이 아직 수렴 전이고
  모델 용량이 데이터에 비해 크다는 뜻이다. 논문의 3~4%p 격차는 수렴까지(학습률 스케줄·수백 라운드) 간 뒤의 값이다.
- 따라서 **이 실험 구간에서 R(w)는 상수**다. 학습량을 줄여도 도달 라운드 수 대가가 측정되지 않고, 라운드당 시간 절감(폭에 비례)만 남는다.
  정식화의 R(w) 항을 실측으로 적합하려면 수렴 근처까지 가는 별도 설정(학습률 감쇠 + 수백 라운드)이 필요하다 — 질문 2 ②에 그대로 가져갈 사실.
- 발표·보고서에서 쓸 문장: "학습량을 1/4 로 줄여도 120라운드 안에서는 정확도 손실이 측정되지 않았다(시드 편차 이내)". "손실이 없다"는 아니다.
