# 실험 — 고정 2연결 비교군 (2026-10-07)

## 1. 왜 하는가

32개 클라이언트 실험(그림 5)의 두 방식은 연결 수가 다르다.

- 기준 방식: 클라이언트마다 출구 A 하나(접속 상한 5 Mbps)로 보낸다.
- AwareNet: 출구 A(5 Mbps)와 출구 B(2 Mbps)를 서로 다른 중계로 보내고, 폭·경로를 매 라운드 정한다.

그래서 기준 대비 단축률(정상 24.6%, 트래픽 몰림 42.6% 등)에는 두 효과가 합쳐져 있다.

    기준 → AwareNet 단축 = (연결을 2개로 늘린 효과) + (스케줄러가 폭·경로를 정한 효과)

가운데에 "연결은 2개를 쓰지만 판단은 하지 않는" 비교군을 두면 두 효과를 따로 잴 수 있다.

| 비교 | 보이는 효과 |
|---|---|
| 기준(1연결) → 고정 2연결 | 연결 수를 늘린 효과 |
| 고정 2연결 → AwareNet | 폭·경로 판단의 효과 |

## 2. 고정 2연결(fixed2)의 정의

| 항목 | 기준(uniform) | 고정 2연결(fixed2) | AwareNet(widthpath) |
|---|---|---|---|
| 모델 폭 | 전원 1.0 고정 | 전원 1.0 고정 | 매 라운드 결정 |
| 출구 A 중계 | 엣지 1~4에 고르게(rr), 고정 | 기준과 같음, 고정 | 매 라운드 결정 |
| 출구 B | 쓰지 않음 | **다른 VM의 엣지**(1→3, 2→4, 3→1, 4→2), 고정 | 매 라운드 결정 |
| 조각 분할 | — | 접속 상한 비율 **5:2** 고정 | 예상 속도 비율 |
| 사전 진단·이동 | 없음 | 없음 | 있음 |

엣지마다 출구 A 8대와 출구 B 8대가 실려 부하가 고르다. 분할 비율을 5:2로 둔 이유는 다음과 같다. 반반(1:1)으로 나누면 느린 출구 B(2 Mbps)가 병목이 되어 비교군이 지나치게 약해진다. 9/9 기록에 따르면 가중치 없이 나눈 경우 출구 B에 39%가 실려 2배 느렸다. 비율은 `FIXED_WEIGHTS=1,1`로 바꿀 수 있다.

코드: `sfl/policies.py`의 `FixedTwo`, 서버 옵션 `--policy fixed2 --multipath --fixed-weights 5,2`.

## 3. 실행 (HPC)

```bash
# 로컬(저장소 루트, 런처 켠 상태): 코드 동기화
bash scripts/exp/hpc_launch.sh sync
# HPC 에서: 3라운드 스모크 (약 5분)
ssh koren-hpc 'cd ~/awarenet; ROUNDS_OVERRIDE=3 SCEN=normal SEEDS=1 bash scripts/exp/run_fixed2.sh'
# HPC 에서: 본 실행 (기본: 트래픽 몰림 → 정상 → 연산 지연 → 용량 변동, 시드 1·2·3, 약 6시간)
ssh koren-hpc 'cd ~/awarenet; nohup bash scripts/exp/run_fixed2.sh > out/fixed2.log 2>&1 < /dev/null &'
# 시간이 부족하면 트래픽 몰림만:  SCEN=traffic SEEDS="1 2 3"
```

- 기존 기준·AwareNet 결과(`out/wp_scen32_<장면>_s<시드>_bothmp_{uniform,widthpath}.jsonl`)는 그대로 두고, 같은 이름 규칙으로 `..._fixed2.jsonl`만 추가한다.
- 교란(트래픽 몰림: 8라운드 엣지 1 용량 56→14 Mbps, 20라운드 복구 / 용량 변동: 7 Mbps 간격 계단)은 `run_scen32.sh`와 같은 일정이다.

python scripts/analysis/fixed2_compare.py      # 화면 + out/fixed2_compare.csv

    기준 대비 전체 단축 = 연결 수 효과(%p) + 판단 효과(%p)

## 5. 검증

- `python tests/test_fixed2.py`: 배정 규칙을 확인한다. 출구 A는 rr과 같고, 출구 B는 다른 VM이며, 엣지당 8+8대, 이후 무개입이다.
- `python -m unittest tests.test_fixed2_e2e`: 합성 데이터로 클라이언트 2대가 2라운드를 돈다. 루프백 엣지 2개로 출구 A·B 종점이 실제로 쓰이고 분할 전송이 되는지 확인한다.
