## 0. 시스템 한 줄
분할 연합학습(기기 앞부분 + 엣지 서버 뒷부분, CIFAR-10 CNN). 리그: HPC 기기 N대 → KOREN(VM 2대 = 엣지 4개, 역터널) → HPC 서버. 회선·엣지 용량은 tc.
스케줄러 = 인지(sense) → 계획(plan) → 실행(act). 손잡이 4개: 모델 폭(연산) · 엣지 바꾸기(SDN 경로) · 두 회선 나눠 보내기(분할 전송) · 즉시 내보내기(조각).
계획 = 결합 최적화 **min max_k T_k(w,s) + λ·평균(1−w)** (λ = 폭 1 을 잃는 값을 초로 환산). 망을 못 바꾸면 폭만, 연산이 문제 아니면 망만, 둘 다면 망 먼저.
