# 공개 자료 검토 및 서론 정리

## 문제 정의

분할을 통해 기기 계산·메모리 부담을 줄이면 매 배치의 통신 완료가 학습 진행 조건이 된다. 폭 축소는 수요와 학습 기회를 바꾸고, 경로 변경은 공유 자원 안에서 처리 능력을 바꾼다. 자원 부족의 원인을 구분하지 않으면 모델 용량이나 전환 비용을 불필요하게 지불할 수 있다. 이 문제를 제한된 기관 제어 권한 아래의 완료 시간·폭 보존 모형으로 표현한다.

## 기여의 범위

FjORD·FedRolex의 부분 모델 선택, AdaptSFL·SuperSFL의 적응형 분할, 통신·연산 공동 최적화에는 선행연구가 있다. 현재 주장은 소유·위임된 호스트와 공유 병목을 전제로 한 시스템 구성 및 실제 장비·연구망 원자료를 추적 가능한 검증에 둔다. 정확도 보존과 순수 네트워크 정책 효과는 아직 분리 입증하지 않았다.

## 원자료 확인

E1-E7에 413개 자료 항목을 연결했다. 중복 참조를 포함한 항목 수이며 413회 독립 실험을 의미하지 않는다. KOREN 24개 로그의 시드별 후반 20라운드 평균, Jetson 세 모드의 30스텝 중앙값, LoRA strict 평가 18문항 점수를 원파일에서 재검산했다. 원본 바이트, ZIP, SHA-256, 원경로를 제공한다.

Jetson 측정 스크립트의 Windows CRLF 사본 해시는 환경 로그의 Linux 파일 해시와 달랐으나, LF 정규화 결과 297ec815b0522c3678161555fddd5318b64a3d155692ba636197635acbd11640으로 일치했다. 공개 사본은 바이트를 보존하고 정규화 해시를 별도로 표시했다. 원시 스텝과 요약 앵커의 배열도 일치했다.

실행 인자의 alpha=1.2는 서버의 지연 기준선 배율이다. 데이터 분할은 별도 alpha-dir 기본값 0.5다. 검토 중 두 값을 잠시 혼동했으나 fed_client, fed_server, 조건 원장으로 구분했다. 과거 데이터 분포 설명을 1.2로 변경하지 않았다.

## 공개 구조

새 공개 저장소 AwareNet의 awarenet 브랜치에는 최종 파일 스냅샷만 게시한다. 원래 개발 저장소는 비공개로 유지한다. 공개 홈페이지는 큰 성능 숫자와 홍보 문구를 제거하고 연구 요약, 문제 정의, 모형, 구현 상태, 조건별 결과, 출처 순서로 재구성했다. PDF는 기존 제출 양식을 유지하고 요약·서론·원자료 부록을 수정했다.

새 실망·학습 실험은 수행하지 않았다. 2026-09-26 가상 실험 결과와 원시 PCAP·Prometheus 시계열 등은 기존 실행 기록을 그대로 연결했다.
