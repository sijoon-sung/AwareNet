## 1. 대회가 주는 사실 (공식 수상작 PDF·보도 확인)

- **대상(장관상)은 2019~2025 7년 연속 '체감형 AI 응용 서비스'.** 치매노인 실종자 찾기 → 아바타 교실 → AI 안내견 → 도로 동적객체 → 딥보이스 탐지 → 클린 스트리밍 → 시청각 해설. 수상권의 70~80%가 서비스형.
- **인프라형은 금·은에서 캡**: 연합학습 5G UAV('19 금), Edge FaaS('21 금), 연합학습 오케스트레이션('23 은), Split Computing 오케스트레이션('24 은).
- ★ **기시감 경보**: 연합학습·분할컴퓨팅은 심사진에게 이미 익숙한 주제. **'25년 "온디바이스-연합학습 의료 AI 플랫폼"은 무관(수상 실패)** → "FL 플랫폼"으로 팔면 진다. 의료 스킨도 접는다.
- **일정**: 챌린저데이 해커톤 **8/28**, 최종평가 **10/30 현장 시연 + 질의응답**, 시상 11/18. 규정상 최종평가가 라이브 시연이므로 **시연 완성도 = 점수**.
- **올해의 변화 2가지 (팀 전언)**: ① 대학원 팀 다수 → 연구 주제 유도 ② 주최가 "KOREN에서만 가능함을 말하라"고 명시 요구. → 역대 공식(서비스가 이긴다)에 올해 보정(연구+KOREN 필연성)을 얹어야 한다.

| 팀/주제 | 강점 | 공략 지점 |
|---|---|---|
| 닿다 — 수어 통역 | 대상 트랙 정합, 감동 데모 | '20 자막·'23 수어학습 기수상 → 참신성 공격 가능. "왜 KOREN인가" 약함 |
| 브롬스타운 — 응급 협진 | 사회적 임팩트 | 실병원 데이터·기관 연계 불가 → 연출 데모에 그침 |
| 모넷랩 — LLM SLA 에이전트 | 시의성 | 학계 표준(vLLM SLO 스케줄러) 대비 학생 구현은 '보장' 아닌 '목표'. 집행면 부재, GPU 문제로 환원 |
| ORAN-DA — LLM AI-RAN / 위성·SDN류 | 화제성 | 실위성/실RAN 접근 불가 → 에뮬 축소. "KOREN 실증"이 컨테이너 가상 토폴로지로 전락 |

**공통 약점 = 측정 없는 주장** (에뮬·목표치·개념도). 우리의 유일무이 자산 = 실측.

## 3. 주장 관리 — 질의응답 방어선 (학술 조사 판정)

| 주장 | 판정 | 발표용 확정 문장 |
|---|---|---|
| 측정 기반 폭 적응 최초 | 축소 | "**SFL에서** in-band 측정(EWMA)으로 매 라운드 FjORD식 중첩 폭을 재배정" — FLuID(NeurIPS'23)·AdaptiveFL(DAC'24)은 비분할 FL·대역폭 in-band 없음, 관련연구 표로 대비 |
| SFL은 전부 시뮬 | 축소 | MergeSFL(Jetson 80대)·ParallelSFL(MobiCom'24)은 실물이나 **랩 LAN**. "**국가 연구망 실WAN 위 SFL 실측은 전례 미확인**"만 주장 |
| 폭×경로 공동 최적화 | 조건부 유지 | 선례 미발견. 단 **실제 경로 제어를 구현·실측한 뒤에만** 주장 (그 전엔 로드맵으로만) |
| 실WAN SFL 공개 데이터셋 | 축소 유지 | 실5G FL 측정 데이터셋(2025) 존재 → "**연구용 WAN 위 SFL on-wire 트래픽 공개는 전례 없음**" |
| 폭+양자화 클라별 결합 | **폐기** | AnycostFL(INFOCOM'23)이 직접 선행. "병목 유형 진단 → 노브 에스컬레이션 **정책**"으로만 프레이밍, AnycostFL 인용 필수 |

**최상위 생존 주장**: "실커널 링크 + KOREN 실WAN 위 SFL 실측, on-wire 데이터 공개 최초 시도."

## 4. 확정 포지셔닝 — 세 겹 한 몸

**서비스 얼굴 (전면)**: **"약한 곳도 배우게 한다"** — 회선·장비 격차 속 배제 없는 공동학습.
망이 나빠지면 모델이 좁아지고, 학습은 멈추지 않고, 아무도 탈락하지 않는다(p_min).
기술 설계(배제 없는 학습)가 그대로 서비스 가치 — 억지 포장이 아니라 번역.
FL·SFL이라는 단어는 전면에서 빼고 "공동학습"으로 말한다(기시감 회피). 의료 스킨 금지('25 무관 전례).

**절정 데모 (최종평가 = 현장 시연)**: **심사위원이 지정한 시점에 실제 링크 열화 주입
→ 수 초 내 진단·폭 재조정 → 학습 지속 → before/after 수치**가 대시보드에 그려지는 폐루프.
경쟁팀의 "결과 영상"과 급이 다른, 살아있는 제어 루프. (오늘 R3 실측이 이미 이 장면 — c3 몰락 → 0.5 좁힘.)

**KOREN 필연성 (주최 요구 직격)**: ① 기관 간 연구망이라는 정체성(우리 실험 조건 자체가 KOREN 실측값: RTT 30.8ms·55Mbps) ② 에뮬로 못 만드는 실WAN 혼잡(버스트 p95 5배) ③ 상용망에서 불가능한 개입 실험(HTB 보호, 향후 QoS/경로) ④ ★ **NIA POP 다지점(서울·대구 등 10개)에 클라 분산 → 지역 간 RTT/대역 이질성 측정표** — "일반 클라우드로 재현 불가"를 수치로. 트레이스+코드 공개 = 유산.

## 6. 미확인 고지

심사 항목별 배점표(공개자료에 없음) · "심사위원 직접 조작 가점" 명문 근거(후기 수준 방증만) ·
"공개 데이터셋이 심사를 좌우" 직접 증거 없음. 이들은 **가설이 아니라 베팅**이며, 베팅의 근거는
"최종평가 = 현장 시연 + 질의응답"이라는 공식 규정이다.
