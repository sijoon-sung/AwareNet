# 리서치 — 최종 결과의 남은 네 가지 (2026-09-10)

9/10 최종 실행 뒤 "만족스럽지 않은 점" 네 가지를 문헌·관행으로 따져 구현·재실행 계획을 정한다. 각 항목: 문제 → 문헌 → 우리 결정.

## 1. 시드 1개 → 반복 횟수

- **문제**: 32대 시나리오는 시드 1·24라운드다. 시드는 데이터 분할(Dirichlet)·초기화·타이밍 잡음을 바꾼다.
- **문헌**: FedScale 벤치마크는 알고리즘 비교에서 5회 실행의 평균을 보고한다([FedScale, ICML 22](https://openreview.net/pdf?id=LZ5cx2yismf), [arXiv 2105.11367](https://arxiv.org/pdf/2105.11367)). Oort 는 FedScale 에 흡수되었고 같은 관행을 따른다([Oort GitHub](https://github.com/SymbioticLab/Oort)). 시스템 논문에서는 3회가 흔하고 오차 막대를 붙인다.
- **결정**: 정상·몰림·연산 느림·변동 4장면을 시드 2·3 으로 두 팔 모두 반복(λ 스윕은 시드 1 유지). 판정은 3시드 평균 ± 범위로 다시 적는다. 실회선 잡음(라운드 CV 8~13%)이 시드 잡음과 같은 크기이므로 3회면 방향은 정해진다.

## 2. "엣지 포화"와 "분할 탓"의 구분 → 출구별 활동 구간 계측

- **문제**: 인지층이 총 처리량·바이트만 보면 "막힌 엣지"와 "느린 출구에 몰아준 분할"이 같은 숫자를 낸다(9/9 변동, 9/10 몰림). 조각 배분을 정적 용량으로 고정해 피했지만 관측이 원리적으로 모자란다.
- **문헌**: 다중경로 전송 스케줄러는 **경로마다** 따로 잰다. BLEST 는 경로별 RTT·in-flight·cwnd·송신창으로 막힘을 추정하고, ECF 는 경로별 완료 시각 예측으로 배분한다([MPQUIC 스케줄러 평가](https://www.diva-portal.org/smash/get/diva2:1220830/FULLTEXT01.pdf), [Stream-aware MPQUIC](https://dl.acm.org/doi/10.1145/3284850.3284855), [FALCON](https://arxiv.org/pdf/2201.08969)). 경로별 계측 없이는 어떤 스케줄러도 경로 상태를 구분하지 못한다는 것이 공통 전제다.
- **결정**: 클라 조각 채널(`mpsend`)이 출구(연결)마다 **활동 구간**(한 전송의 첫 조각 시작~마지막 조각 끝, 올리기·내리기 각각)을 누적해 라운드 보고에 `up_t/dn_t` 로 싣는다. 인지층은 흐름별 실효율(바이트/활동 시간)의 합으로 엣지 처리량을 재고, 접속 상한 합과 견줘 포화를 판정한다. 건강한 엣지에서는 흐름마다 제 상한(A 5M·B 2M)을 내므로 분할이 치우쳐도 합이 접속 합과 같고, 막힌 엣지에서는 합이 용량으로 떨어진다. 걸친 기기(1+3)도 흐름마다 제 엣지에 귀속된다. 옛 로그(활동 구간 없음)는 종전 규칙으로 처리(재생 호환). 설계기록 §13-5.

## 3. 교란 첫 라운드의 전원 폭 0.75 → 망 변화 라운드에는 폭을 손대지 않는다

- **문제**: 몰림 R9~10 에 전원 폭 0.75 가 두 라운드 나타났다 되돌아온다. 교란 첫 라운드의 관측(147 s)으로 만든 목표 배정은 이동이 반영되기 전이라 전원을 망 병목으로 보고 한 칸 축소의 이득이 가격을 넘겼다. 목적함수의 답이지만 과도 반응이다.
- **문헌**: Kubernetes HPA 는 축소 결정에 **안정화 창**(기본 300 s)을 두어 창 안의 최대 권고값을 쓴다 — 순간 지표로 되돌릴 결정을 하지 않게 한다([Kubernetes HPA](https://kubernetes.io/docs/concepts/workloads/autoscaling/horizontal-pod-autoscale/), [KEP-853](https://github.com/kubernetes/enhancements/blob/master/keps/sig-autoscaling/853-configurable-hpa-scale-velocity/README.md)). 다중경로 스케줄러도 경로 상태 변화 직후의 과도 반응을 억제한다([FALCON](https://arxiv.org/pdf/2201.08969)).
- **결정**: 어느 엣지든 용량 관측이 5% 넘게 바뀐 라운드(망 변화 라운드)에는 이동만 하고 **폭은 지난 라운드 값을 유지**한다. 이동이 자리 잡은 다음 라운드부터 가격을 따진다 — "둘 다면 망 먼저"의 시간 축 판. 폭을 올리는 쪽은 이미 2라운드 재확인이 있으므로 이 규칙은 내리는 쪽의 대칭이다. 시험 test_plan2 ⑮, 최종 로그 재생으로 R9 에 폭 유지 확인.

## 4. 정확도 미측정 → λ 눈금의 정확도 축

- **문제**: 폭 대가를 문헌으로만 대신했다. λ 가 "시간–정확도 눈금"이라는 주장은 시간 축만 실측했다.
- **문헌**: HeteroFL·FjORD·FedRolex 는 작은 폭 기기 비율이 클수록 전역 정확도가 1~5%p 떨어지고, 같은 기기만 계속 작으면 편향이 생긴다고 보고한다(리서치_폭축소_정확도대가 §1). 24라운드는 잡음(4~6점)이 차이보다 커서 판정이 안 된다(9/8 결합 실험).
- **결정**: 8대 혼합(r8mix, 라운드 ≈ 10 s)에서 λ ∈ {18, 70, 280} + 균등을 **200라운드·2시드** 돌려 λ 마다 (평균 폭, 라운드, 마지막 50R 정확도)를 얻는다. 32대는 라운드가 50 s 라 200R 이 3시간/팔이라 8대로 한다. 판정: λ 가 작을수록 폭·정확도 ↓, 라운드 ↓ 가 단조(잡음 5점 밖의 차이만 말한다).
