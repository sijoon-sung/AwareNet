## 예시 문구를 그대로 채택하지 않은 부분

- AdaptSFL·SuperSFL이 모두 망 전체 제어 권한을 가정한다는 비교는 1차 논문에서 확인되지 않아 제외했다. 제어 변수와 본 과제의 실행 문제를 비교했다.
- 42.6%를 우회 경로만의 효과, 40.3%를 폭만의 효과로 단정하지 않았다. 이 수치는 출구 수와 정책이 함께 다른 시스템 비교다. 실제 경로·폭 로그로 관찰 동작을 설명했다.
- 두 시드 평균 정확도가 가깝다는 결과와 통계적인 동등성은 구분했다. λ가 작을 때의 정확도 감소도 함께 제시했다.
- 32는 HPC의 CPU 논리클라이언트 프로세스 수로 표기했다. 축소·실측값 주입 기록은 새로운 현장 측정으로 바꾸어 쓰지 않았다.

## 코드와 맞춘 판단식

`sfl/plan.py`의 경로 점수는 최대 지연과 평균 지연의 합에 N을 곱한 값이다. 폭 비용은 배치당 시간 기준에서 λ/B를 사용하므로 본문에서는 라운드 시간 단위로 변환했다. 폭 축소 후보는 예상 이득의 90%가 λ×평균 폭 감소량을 넘을 때 채택한다. 실제 적용은 한 단계, 복귀는 두 번 연속 확인한다.

경로 전환 문턱은 이동 대상 시간의 10%와 전환 비용이며 전체 라운드의 10% 단축 규칙과 구분한다. 망 용량 변화가 설정 용량의 5%를 넘으면 해당 라운드의 폭을 유지한다. 관측 용량은 경로 결정에, 설정 용량과 공유 배정은 분할 비율에 사용한다.
