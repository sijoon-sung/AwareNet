# 서술형 보고서의 신규성과 출처 검토

이 문서는 [서술형 보고서](../01_제출발표/AwareNet_서술형보고서_2026-09-26.md)의 편집 근거다. 제출 본문의 서술과 구별하여, 어떤 양식을 참고했고 어떤 주장을 채택·제외했는지 기록한다. 2026-09-26의 로컬 원격 추적 브랜치를 읽었으며 이번 작성 중 원격 최신 상태를 새로 가져온 것은 아니다.

검색한 브랜치와 현재 파일에서 공식 원본 HWP/HWPX/DOCX는 발견되지 않았다. 확인한 PDF 자체도 HWP에 붙여넣는 본문 초안이라고 명시한다. 따라서 공식 HWP의 셀 배치까지 동일하게 복원했다고 주장하지 않는다. 표지의 날짜는 실제 제출일 대신 작성 기준일로 적었다.

도표 개선 후 최종 PDF는 24쪽으로 표지 1쪽, 요약문 3쪽, 목차 1쪽, 본문·참고문헌 19쪽이다. 대제목 15pt, 본문 13pt와 A4를 적용했다. 휴먼명조가 설치되어 있지 않아 PDF에는 HY신명조를 사용했다. HTML에는 휴먼명조를 우선 지정하여 한글 서식으로 옮길 때 사용할 수 있게 했다. HY견명조(H2MJRE)는 휴먼명조가 아니므로 사용하지 않았다.

그림 9개와 표 6개를 연결하여 전체 구조, 구현 상태, 실제 실행 위치, 교란 조건, 비교 결과를 표시했다. 도식의 제어·데이터 흐름 및 권한 경계는 현재 코드의 상태를 설명하며, 미통합 SDN 프로토타입을 실증 완료로 표시하지 않는다. 그림 7의 선은 `run_scen32.sh`와 `scenario_perturb.sh`에 지정한 조건으로서 관측 처리량이 아니다. 그림 8은 기존 3시드 평균을 표시하며, 기준선과 결합 정책의 출구 수 차이를 범례와 본문에 명시했다. 32개/8개 프로세스와 Jetson·LoRA 실행은 각각의 조건으로 구분했다. 도식의 원자료 10개 해시는 `output/prose_awarenet/figures/sources.json`에 기록했다.

## 선행연구와의 비교

9/26 후속 정정에서는 ‘일반 단말까지 하나의 SDN 도메인’이라는 인상을 제거했다. 기관별 관리 권한·위임이 필요하며, 현재 실험팀의 호스트 제어권은 그 일반화의 증거가 아니다. 실커널 tc 큐/필터와 응용 종점/분할을 구별하고, 과거 ACK 보호는 기본 비활성인 소패킷 분류임을 확인했다. 패킷 직렬화와 가정한 AI 판단 시간 그림은 분석 예시이며 추론 벤치마크가 아니다. 자세한 감사는 [경로·아키텍처 문서 §8](../04_설계기록/네트워크중심_아키텍처_및_경로주장_2026-09-22.md)과 코드 해시 원장에 있다.

아래는 문헌의 목적과 제어 변수에 대한 비교다. 논문마다 다른 데이터·장비에서 보고한 수치의 우열 비교가 아니며, 해당 범위에서 학계 최초임을 확정하는 전수 문헌 조사도 아니다.

| 선행연구와 원문 | 해당 연구의 제안 | AwareNet과의 관계 및 허용되는 주장 |
|---|---|---|
| [FjORD v5](https://arxiv.org/abs/2102.13451v5) | Ordered Dropout, 포함 관계의 부분 모델 | 폭 축소의 기반. 부분 모델 자체의 신규성은 없음 |
| [FedRolex v2](https://arxiv.org/abs/2212.01548v2) | 순환하는 부분 모델 추출 | 알고리즘 교체는 네트워크 기여를 증명하지 않음. 교체 후 우월성은 실험 전 주장 불가 |
| [AdaptSFL v4](https://arxiv.org/abs/2403.13101v4) | 모델 분할과 기기 측 집계 제어 | 자원 적응 및 통신·연산 균형이라는 문제에 중복 존재 |
| [SuperSFL v2 §3.1](https://arxiv.org/html/2601.02092v2) | 슈퍼네트워크, 깊이 할당, TPGF, 장애 시 로컬 학습 | 초기 메모리·RTT 기반 깊이 할당이 존재. 현재 CNN 실행은 고정 깊이이며 TPGF를 구현했다고 하지 않음 |
| [Liang 등 v1 §IV](https://arxiv.org/html/2501.01078v1) | 분할 지점·통신·연산 자원 CCC 결합 최적화 | ‘학습과 망을 함께 최적화한 최초’ 주장을 직접 제한. AwareNet은 허용 중계 경로와 공유 병목, 구현 권한을 구체화 |
| [Shi 등](https://arxiv.org/abs/2007.07174) | 장치 선별 및 대역폭 공동 배분 | 완료 시간·자원 공동 고려는 기존 연구. 과거 워터필링을 독자 발명으로 재사용하지 않음 |
| [LoRA](https://arxiv.org/abs/2106.09685), [SplitLoRA](https://arxiv.org/abs/2407.00952) | 저랭크 미세조정 및 분할 연합학습 결합 | 실제 KOREN 배치·집계 실습의 성과. 새 LoRA 알고리즘이나 VFL 발명이 아님 |
| [SHRiNK](https://web.stanford.edu/~balaji/papers/03shrinkaCONF.pdf) | 입력·자원을 함께 축소한 네트워크 성능 예측 | 축소 실험의 참고. 기기 수·CPU·학습 분포의 동등성 보장까지 확장 불가 |

채택 문장: **“본 과제는 운영자가 제어할 수 있는 자원과 허용 경로의 범위 안에서 모델 폭과 네트워크 배정을 공통 완료 시간 모형으로 연결하고, KOREN 및 실제 하드웨어 기록으로 그 동작과 한계를 검토한 시스템을 제시한다.”**

이는 시스템 설계·구현·실증의 기여 문장이다. 새 이론이나 선행연구에 없는 모든 구성의 최초 결합을 입증한 문장이 아니다. 현재 증거로 알고리즘 논문의 강한 신규성을 확정할 수 없다는 판단을 본문에도 남겼다.

원자료 숫자는 `configs/measurements/final_report_evidence_2026-09-26.json`에, 집계 방식은 `scripts/analysis/build_final_visual_report.py`에 있다. 이번 작업은 보고서 작성이며 새로운 학습 실험을 수행하지 않았다.

## 제외한 예전 주장

기존 중간보고서의 ‘68%가 통신 병목’, FedScale의 작은 상관계수를 실제 기기 특성의 독립성으로 해석한 문장, 모든 정확도의 동일 수렴 보장, 누락 클래스의 영구 손실, 최악의 경우 무조건 현행과 같다는 보장은 새 본문에 이관하지 않았다. 과거 참여자 선별의 정확도·참여 지니·TTA 수치도 현재 CNN SFL 결과와 섞지 않았다.

‘경로 변경’은 중계 종단점 선택이며 서버 상태 이동이 아니다. ‘결합’은 바이트 재조립, 기울기 대응, 연합 집계의 서로 다른 단계로 풀어 썼다. ‘세로’라는 표현은 모델 층 분할의 직관으로 이해하고, 특징 분할 기반 수직 연합학습 VFL이라는 기술 용어로 바꾸지 않았다.
