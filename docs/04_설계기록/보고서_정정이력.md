## 4. 보고서 262행 부근

**고치기 전**

```
**두 층이 서로 다른 물리 구간에 놓인 것**이 핵심이다. 학습 손실이 배분으로 내려가고 바뀐 도착 순서가 다시 학습 신호가 되어 응용과 망이 **폐루프로 맞물린다.**
```

**고친 뒤**

```
**두 층이 서로 다른 물리 구간에 놓인 것**이 핵심이다. 학습 손실은 **선별층**의 기준이 되고, 선별 결과가 각 엣지의 준비 시각 $r_e$를 바꿔 **배분층**의 입력이 된다. 바뀐 도착 순서는 다시 다음 라운드의 학습 신호가 되어 응용과 망이 **폐루프로 맞물린다.** 엣지 경계 밖으로 나가는 신호는 $r_e$, $P$, $C_B$ 셋뿐이다.
```

**왜** — 배분층 수식(need·T*·a_e)의 입력은 r_e, P, C_B 뿐이고 학습 가치 v_i가 들어가지 않는다. 원 문장은 **자기 문서 안에서 모순**이었다. 실제 결합 경로(선별 결과 → r_e → 배분층)로 고쳤다.

```

**Oort보다 지니·0회·목표 정확도 도달이 모두 낫다.**
```

**고친 뒤**

```
| 선별층만 | 본 과제 | 균등 | 80.41±1.22% | 38.40% | 40.4s | 32.6s | 7.8s | 0.200 | 0대 | 169s |
| 배분층만 | 무작위 | 본 과제 | 77.91±2.10% | 37.71% | 35.7s | 32.8s | **2.8s** | 0.404 | 19.7대 | 139s |

```


**고친 뒤**

```
**GPU 없는 환경, 난수 데이터에서도 시간 축의 순서가 그대로 재현된다**(34.2 < 35.7 < 38.8 < 39.8 < 40.7초). 정확도 순위는 데이터가 다르므로 재현되지 않는다. 이 실험이 뒷받침하는 것은 2×2 절개의 **시간 축 주장**이다 — 선별층만과 본 과제의 라운드별 정확도가 **비트 단위로 일치**한다(13.70/18.65/20.20/24.30/18.93/27.80…). **배분층은 정확도를 1비트도 바꾸지 않고 시간만 38.8→34.2초로 줄였다.**
```

**왜** — CPU 재현에서 재현된 것은 **시간 축 순서**이고 정확도 순위는 데이터가 달라 역전된다(본 과제=선별층만 > 배분층만 > FedAvg > Oort). "순서가 그대로 재현된다"는 과했다.
