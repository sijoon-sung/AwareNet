# G3 — Jetson·비전(ViT) 적극 활용 계획 (12번 문서)

> 목적: Jetson 을 "보유 장비"에서 **실증의 주연**으로. 배선은 이미 있다 —
> `models_vit.py`(폭=헤드·은닉차원) + `fed_server/client --arch vit` 지원 완료.
> 없는 것은 실행 계획과 판정선이고, 이 문서가 그것이다.

## 0. 먼저 — 카메라를 사야 하나?

**필수 아님, 그러나 싸니까 1~2개 사두는 것을 권장.**

| 용도 | 카메라 필요? | 판단 |
|---|---|---|
| G3 본실험 (전력모드 이질성·폐루프) | ❌ | 저장 데이터셋(CIFAR-10/Tiny-ImageNet)으로 충분 — 학습 주장에 카메라는 불필요 |
| 시연 서사 ("현장 카메라 노드가 데이터를 반출하지 않고 공동 학습") | ⭕ 있으면 강함 | 실물 카메라가 찍고, 그 자리에서 앞단을 돌리는 장면은 "데이터가 안 나간다"의 체감 장치 |
| 라이브 캡처 학습 | △ | 시연용 소량 파인튜닝 정도 — 본 수치 주장에는 안 씀 |

- 사양: **범용 USB 웹캠 1~2만 원대면 충분** (UVC 표준 = 리눅스 드라이버 무설정).
  CSI 카메라(라즈베리파이용)는 Jetson 포트 호환 확인 필요해 USB 가 안전
- ⚠ 개인정보 수칙: 시연·수집 모두 **사물/보드/소품만 촬영** — 사람 얼굴 프레임 금지.
  캠페인 동의서 원칙과 동일선

## 1. Jetson 의 세 가지 역할 (전부 기존 설계에 꽂힘)

**역할 A — 자연 이질성 실물 (G3 본편).** 전력모드가 곧 "연산 능력이 다른 기기"다:

| nvpmodel 모드 | 의미 | 실험에서의 역할 |
|---|---|---|
| MAXN | 최대 성능 | 정상 기기 |
| 15W/10W 등 | 제한 성능 | 연산 낙오자 — **주입이 아니라 실물** |
| 런 중 모드 전환 | `sudo nvpmodel -m <k>` | **조건3의 연산판** — 회선이 아니라 기기가 몰락하는 교란 |

지금까지의 연산 낙오자는 스레드 수로 합성했다(E11). Jetson 은 그것의 실물 확인이다.

**역할 B — 혼합 리그의 실물 클라 (시연의 머니샷).** 폐루프 라이브 리그(로컬 클라 3대)에
Jetson 1대를 **진짜 기기**로 편입 — 심사위원 앞에 물리 보드가 놓여 있고, 그 보드의
전력모드를 낮추면(또는 회선을 조이면) 화면에서 그 노드의 폭이 좁아진다. "실물이
폐루프 안에 있다"는 것이 영상 데모와의 결정적 차이.

**역할 C — 에너지 축 (백로그 P2-10).** `tegrastats` 로 보드 전력을 실측 —
**폭 p 별 라운드당 에너지(J)** 곡선. "폭을 줄이면 엣지 전력도 준다"는 경쟁팀이
물리적으로 못 만드는 수치다. 기존 Jetson 계측 리그(`jetson/`) 재사용.

## 3. 배선 현실 (정직 고지)

- **네트워크**: Jetson 은 게이트웨이(집결지 패턴)로 랩 PC 에 붙고, PC↔KOREN 은 기존
  경로. Jetson 이 KOREN 에 직접 붙을 필요 없음 — 9번 문서의 계층 구조 그대로
- **torch on Jetson**: aarch64 는 pip 기본 휠이 아니라 **JetPack 동봉/NVIDIA 제공 휠**
  사용 — `deploy/remote/remote_setup.sh` 의 cpu/cuda 분기와 별도로, Jetson 은 기존
  이미지의 torch 를 쓰고 저장소만 push (README 에 jetson 절 추가 예정)
- **fed_client 는 무수정 동작 예상**: `--device cuda --bind <IP>` — Jetson GPU 를 쓰는
  유일한 클라가 되므로 GPU 경쟁 오염 없음(1보드 1클라)
- **ViT 데이터**: CIFAR-10 그대로(32² 리사이즈 ViT-small 구성 — models_vit `--vit-cfg`),
  필요 시 Tiny-ImageNet. 카메라 캡처는 시연 전용 소량
- **시간**: G3-1~3 은 리그가 이미 있어 보드 셋업 포함 1~2일. G3-4 는 반나절

## 4. 순서 제안

R4b·R5-Q(P0) 뒤, G-L2 와 병행 가능한 첫 여유 슬롯에 **G3-1 부터**. 카메라는 지금
주문(배송 시차) — 도착 전 실험엔 불필요하므로 블로킹 없음.
