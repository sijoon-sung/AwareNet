# 기획 — 캠퍼스 실사용 측정 캠페인 (1단)

> **상태: 기획. 실행 전.** 작성자 스스로 회의적 시선을 반영한다 — **파일럿 게이트(§7)를
> 통과하기 전에는 예산을 1원도 집행하지 않는다.** 실패해도 비용 0으로 접을 수 있는 구조.

## 0. 한 줄

에타로 모집한 재학생 50~100명이 **웹페이지 3분 접속**(설치 없음)으로 기기·회선을 실측
→ "캠퍼스판 FedScale" 이질성 분포 확보 + 서비스 얼굴("약한 곳도 배우게 한다")의 실사용 근거.

## 1. 이게 사주는 것

| 지금 | 캠페인 후 |
|---|---|
| 이질성 근거 = FedScale (해외 50만 클라, 남의 트레이스) | **우리 캠퍼스 실측 분포** (p95/p5 배율, WiFi/LTE, 기기 분포) |
| "실사용자" 주장 없음 | "재학생 N명 실측 + 통제 노드 M대 실학습" — 정직하게 분리된 실운영 서사 |
| 컨트롤러 프로파일 = 합성/HTB 주입 | 실측 분포에서 뽑은 프로파일 |

발표 한 줄: **"우리 학교 안에서만 회선이 X배 갈립니다 — 저희가 직접 쟀습니다."** 못 베끼는 숫자다.

## 2. 참가자 경험 (3분)

1. 에타 글 → 링크 클릭 (공개 HTTPS URL, 앱 설치 없음)
2. 동의 화면 — 수집 항목 전부 명시 (§4)
3. 자동 측정 ~60초: RTT 반복, 다운/업 스루풋(**1인씩 큐** — 대기표 표시), 기기 정보
4. (선택) WiFi ↔ LTE 전환 후 1회 추가 — 같은 사람의 두 회선
5. 기프티콘 응모 — 연락처는 **별도 폼**(측정 데이터와 분리 저장, 추첨 후 삭제)

## 3. 시스템 — 로컬 호스팅 (KOREN IP 제약과 무관)

```
참가자 폰 ──HTTPS(Cloudflare Tunnel 무료·아웃바운드 전용)──▶ 본인 PC 게이트웨이
                                    (FastAPI 측정 서버 + SQLite, WSL)
게이트웨이 ──기존 허용 경로──▶ KOREN 판교 (배치 후송 — 실시간 불필요)
```

**측정 방법론 가드레일** (계측 오염 교훈의 재적용):
- 동시 측정 **1인 큐** — 게이트웨이 업링크가 병목이 되어 전원이 게이트웨이 회선을 재는 사고 방지
- 반복 3회 **중앙값** 채택, slow-start 보정(τ 규칙 실측 그대로 — 램프업 ~1초 구간 제외)
- 게이트웨이 업링크 실효치를 **사전 실측·공개** — 그 값이 측정 상한임을 리포트에 명시
- IP+기기 해시로 중복 참여 컷 (해시 후 원본 IP 폐기)

## 4. 수집 항목과 동의 — 전부 명시, 이것만

- **수집**: 타임스탬프 · RTT 통계 · 업/다운 스루풋 · 접속망 종류(WiFi/셀룰러, 자가선택 병행) ·
  브라우저가 주는 기기 정보(UA, 코어 수, 메모리 등급 — API 한계 명시) · 교내/교외 자가선택
- **미수집**: 이름·학번·정확한 위치·기기 고유 식별자·콘텐츠. IP는 중복방지 해시 후 폐기
- 기프티콘 연락처는 분리 보관, 추첨 즉시 삭제. 문의 채널 명시

## 5. 예산

기프티콘 1만원 × 50~100명 = **50~100만원** (대회 예산 항목 확인 필요). 인프라 비용 **0**
(로컬 호스팅 + 무료 터널). 파일럿 게이트 실패 시 집행액 **0**.

## 6. 리스크 — 회의적 시선 그대로

| 리스크 | 대응 | 킬/강등 기준 |
|---|---|---|
| 아무도 안 옴 | 지인 파일럿 10명 먼저, 에타 글에 "3분·1만원" 선명하게 | 에타 48시간 <20명 → 규모 30명 축소 + 연구실·동아리 순회로 전환 |
| 측정 쓰레기값 (혼잡 순간치) | 반복 3회 중앙값, 이상치 컷 | 파일럿에서 같은 기기 2회 편차 >50% → 방법 재설계 후에만 진행 |
| 기프티콘 목적 무성의 | 측정이 자동이라 무성의가 불가능한 설계 | — |
| 게이트웨이 병목 | 1인 큐 + 업링크 실효치 명시 | 업링크 < 참가자 p95 예상 → "상한 명시 측정"으로 강등 |
| 학교 망이 터널 차단 | Cloudflare Tunnel은 아웃바운드 전용이라 보통 통과 | 차단 시 → 자택 회선 호스팅으로 이전 |
| 개인정보 민원 | §4 최소수집 + 동의 + 분리보관 | — |

## 7. 판정 (사전 등록)

- **파일럿 게이트 (예산 집행 전, 지인 10명)**: ① 완주율 ≥80% ② 측정 재현성 통과(§6 기준)
  ③ 터널·큐 무사고 → 셋 다 통과해야 에타 집행. 하나라도 실패 → 비용 0으로 종료 또는 재설계
- **본 캠페인 성공선**: 유효 표본 ≥50명, 기기·회선 분포표, 캠퍼스 p95/p5 배율 산출
- **산출물**: `out/campus_hetero_YYYYMM.csv` + 분포 리포트 1장 (발표·논문 공용)

## 9. 이음5G와의 관계 (헷갈리지 않기)

이 캠페인(1단)은 이음5G와 **무관**하다 — 참가자는 게이트웨이까지만 온다.
이음5G 거점은 2단(대표 단말 실측)의 **선택지**: 기본 구조는 "우리 장비를 들고 대전 거점
시험실에 가서, 그 방의 5G 전파에 붙여, KOREN 백본을 타고 판교까지 잰다"이다.
방문 없이 쓰는 원격 이용이 가능한지는 NOC 문의 1순위 질문. **필수가 아니라 보너스** —
안 되면 K1(판교–대전 유선 2사이트)만으로 실WAN 주장은 성립한다.
