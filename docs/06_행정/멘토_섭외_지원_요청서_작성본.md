## 멘토 섭외 지원 요청 사유

본 과제는 **연합학습(AI)과 SDN 네트워크 제어를 결합한 크로스레이어(cross-layer) 융합 주제**로, 두 분야를 동시에 자문할 수 있는 전문가를 팀 자체 네트워크로 찾기 어렵습니다. 교내 자문(충남대 양희철 교수님, 최향창 교수님)으로 연합학습 알고리즘 측면은 3회 검토를 받았으나, **KOREN 광역망 실증·SDN/QoS 제어·트래픽 엔지니어링 관점의 산업계/연구계 전문가**는 섭외 경로가 없어 지원을 요청합니다. (기존 자문 교수님들과는 일정 조율도 방학·학기 초로 인해 어려운 상황입니다.)

| 2순위 | **네트워크/데이터/AI** (SDN·QoS 대역폭 제어, KOREN 광역망 실증, 트래픽 엔지니어링) |

## 희망 자문 내용

과제: **KOREN SDN 기반 AI 인지형 동적 네트워크 플랫폼(AwareNet)** — 연합학습에서 마감 초과로 버려지는 저속 노드를, 학습 가치 기준의 SDN 대역폭 재배분으로 마감 안에 도착시키는 시스템. 현재 알고리즘 예비 검증과 시스템 구현을 마치고 KOREN 실망 100노드 본실험을 앞두고 있어, 아래 항목의 자문을 희망합니다.

1. **실험 설계 타당성** — 4비교군(정적 캡 / 균등 동적 배분 / 가치 선택만 / 제안 시스템 전체) × 경합 스윕 구조와, 마감 사전 규칙(균등 배분 기준 P50 도착시간 × 1.5)이 학계·산업 관행상 설득력 있는 구성인지
2. **평가 지표 선정** — 전체 정확도가 아닌 **희귀 클래스 정확도·희귀 노드 마감 내 도착률**을 1차 지표로 세우는 것의 타당성, 반복 횟수(3~5회)와 통계 검정 수준
3. **네트워크 실증 방법론** — KOREN 광역 구간(판교↔대전 140km)에서 "KOREN이어야 했음"을 입증하는 측정 항목 설계, tc 기반 셰이핑·이중 VXLAN 제어/데이터 분리 구성의 개선점
4. **시스템 강건성** — 클라이언트 자기보고 값(계산시간·샘플 수)의 게이밍 방어, 100노드 확장 시 제어 루프에서 먼저 깨질 지점
5. **기여 위치 정립** — 자원 배분·스케줄링 선행 연구(Oort, FedBuff, TiFL, BwE 등) 대비 본 설계의 기여로 주장 가능한 범위와 아닌 범위의 구분
