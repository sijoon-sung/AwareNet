## ⚠ 먼저 — 검색 과정에서 나온 본문 오류 두 건

### ① 27쪽 "업계도 …고 진단하며[25]" — **주체가 틀렸습니다**

본문이 따옴표로 인용한 문구 **"병원 안에 쌓여 있는데 제때 접근하지 못한다"** 의 실제 출처는
**염민섭 한국보건의료정보원장**의 전자신문 기고문입니다 — 원문 축자 일치:

> "문제는 이런 데이터가 세상에 없어서가 아니라 **병원 안에 이미 쌓여 있는데도 제때 접근하지 못한다**는 데 있다."

보건복지부 산하 공공기관장이지 **"업계"가 아닙니다.**

**고칠 문장**

```
(전) 업계도 "병원 안에 쌓여 있는데 제때 접근하지 못한다"고 진단하며[25],

(후) 업계는 국내 의료데이터의 97%가 사일로 상태라고 진단하고[25],
     보건의료정보원장도 "병원 안에 이미 쌓여 있는데도 제때 접근하지 못한다"고 적었다[26],
```

→ 이렇게 나누면 **인용 가능한 수치(97%)** 도 함께 얻습니다.

### ② 27쪽 `[27]` Rockwell 보고서 — **그 문장을 뒷받침하지 않습니다**

본문 `"특정 라인·설비의 결함은 그 사업장에만 존재하며"` 에 Rockwell 리포트를 달았는데,
보도자료·업계 보도를 전수 확인한 결과 **결함 분포의 사업장 특이성(non-IID)에 관한 서술이 없습니다.**
표준화·상호운용성 서술도 없어 `[28]` 자리에도 맞지 않습니다.

Rockwell 이 실제로 뒷받침하는 것은 **"제조업체 50%가 품질관리에 AI/ML 적용 계획"** 하나뿐입니다.

## ⚠ 표 4의 배분 기준 셀도 고쳐야 합니다

본문 12쪽 표 4에서 무선 FL 대역 할당 행의 배분 기준을 **"채널 상태 + 공정성"** 이라 적었는데,
`[15]` `[16]` **두 논문 모두 공정성을 다루지 않습니다.** 목적함수는 수렴 하한·모델 정확도입니다.

```
(전) 채널 상태 + 공정성
(후) 채널 상태 + 지연/수렴 기여
```

→ 이렇게 고치면 서지와 정확히 맞고, **"선행은 회선 지표로 나누고 본 과제는 학습 가치로 나눈다"** 는
대비 구도가 오히려 선명해집니다.
