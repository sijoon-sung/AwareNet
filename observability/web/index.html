격리된 가상 실험입니다. 실제 Linux tc·TCP·패킷을 사용하지만 새 KOREN 실측이나 학습 정확도 실험은 아닙니다. TCP ACK RTT와 텐서 완료 시간은 다른 지표입니다. 재전송 분석 플래그를 손실률로 해석하지 않습니다. 공개 홈페이지에는 이 실행의 기록을 제공하며 계측 서비스는 로컬에서 실행됩니다.
