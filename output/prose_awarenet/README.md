# AwareNet 서술형 보고서

`AwareNet_서술형보고서.pdf`는 중간보고서 장·절을 따른 24쪽 보고서다. 표지 1쪽, 요약문 3쪽, 목차 1쪽, 본문·참고문헌 19쪽이다. 문단 중심의 본문에 그림 9개와 표 6개를 배치했다. 그림은 논문용 도식으로 다시 그렸다. 짧은 명칭·기호·연결선으로 구조를 나타내고 설명과 적용 범위는 본문 및 갤러리 캡션에 두었다. PDF에는 벡터로 삽입했다.

| 빠르게 확인할 내용 | PDF 쪽 | 자료 |
|---|---:|---|
| 성과와 해석 범위 | 4 | 요약 표 1 |
| 구성 요소별 구현·검증 상태 | 8 | 표 2 |
| 전체 구조와 SDN 권한 경계 | 9 | 그림 1 |
| 폭·경로 결정과 전송·집계 | 10~12 | 식 1·2, 그림 2·3 |
| 기관 경계와 커널·에이전트 | 13~14 | 그림 4·5, 커널 설정·TCP 개선·판단 시간 규모 |
| 실제 실행 위치와 교란 조건 | 15~16 | 그림 6·7, 32개/8개 프로세스 비교 표 3 |
| 기존 KOREN 결과 | 17 | 그림 8, 표 4 |
| Jetson·모델 메모리·LoRA | 18~19 | 표 5·6, 그림 9 |

[그림 갤러리](figures.html)에서 도식 9종을 볼 수 있고 [PNG·SVG 묶음](AwareNet_구조도_조건그림.zip)으로 한글·Word·슬라이드에 재사용할 수 있다. PNG는 가로 2,400px, SVG는 텍스트와 도형 편집용이다. SVG 글꼴은 맑은 고딕이며 다른 환경에서는 대체 글꼴을 확인해야 한다. 그림별 조건의 출처는 `figures/sources.json`에 기록했다.

`AwareNet_서술형보고서.html`은 브라우저에서 읽거나 한글·Word에 본문을 옮길 때 사용할 수 있다. 원고는 [Markdown](../../docs/01_제출발표/AwareNet_서술형보고서_2026-09-26.md)에 있다. HTML은 HWP 파일이 아니며, 한글로 옮길 때 쪽 나눔과 목차는 해당 프로그램에서 다시 확인해야 한다.

확인한 양식 지침은 A4, 휴먼명조, 대제목 15pt·본문 13pt다. 휴먼명조는 현재 환경에 없어 PDF에 HY신명조를 대체 사용했다. HTML에는 휴먼명조를 우선 지정했다. 공식 HWP 원본은 검색한 브랜치에서 찾지 못했으므로 원본 서식의 완전한 복제라고 표시하지 않는다.

신규성·비교 조건·출처 검토는 [편집 근거](../../docs/03_리서치/서술형보고서_신규성및출처검토_2026-09-26.md)를 참고한다. 새 학습 실험 없이 기존 자료를 사용했다.

생성 스크립트는 `scripts/analysis/audit_network_implementation.py`, `scripts/analysis/build_report_diagrams.py`, `scripts/analysis/build_prose_report.py`다. 이 순서로 Codex의 bundled Python과 ReportLab을 사용하여 실행하며 보고서 스크립트의 `--render`는 Poppler 페이지 PNG를 생성한다. 원자료 해시와 산출물 검사 기록은 `verification.json`에 남긴다.
