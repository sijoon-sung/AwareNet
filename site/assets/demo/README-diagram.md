# AwareNet 시연 영상 10월 2일 개정

114.16초 · 1920×1080 · 25 fps · 무음.
실험 기록 조회 화면을 연속 녹화하고 MP4 코덱으로 변환했다.

CNN·LoRA 학습 화면에는 실제 경과 시간을 기준으로 계산한 압축 재생 표시를 넣었다.
LoRA 답변은 저장 모델의 실제 출력이며 텍스트 표시를 1.2초로 압축했다. 실시간 추론 스트리밍을 뜻하지 않는다.
KOREN 장면은 라운드당 1.3초로 압축하고 용량 축소·복구 구간을 강조했다.
마지막 비교는 24개 원로그의 3시드 집계이며 연결 1개와 2개의 전체 구성 비교다.
109~112초는 공개 코드·원자료 주소를 표시한다. 녹화 시작 준비 화면 때문에 인코딩 시각에는 소폭 차이가 있다.

원래 viewer-data.json과 학습·추론·네트워크 원로그는 변경하지 않았다.
KOREN 내부 라우터 제어와 T-SDN·L2VPN 적용은 후속 검증 대상이다.
