# 리서치 — 폭 축소의 정확도 대가와 "망을 고치면 폭을 덜 깎는다" (2026-09-08)

3번 결합 실험의 논리: 라운드 목표 D 가 주어지면(응용이 정함), 단순 분할학습은 느린 기기를 D 안에 넣기 위해 **폭(모델 너비)**을 깎는 수밖에 없고 그 대가는 정확도다.
망 손잡이(엣지 변경·분할 전송·즉시 내보내기)는 정확도 대가가 없으므로 먼저 쓰고, 그래도 D 를 못 맞추는 기기(연산 낙오자)만 폭을 깎는다 → 같은 D 에서 폭 합이 크고 정확도가 높다.
여기서는 (1) 폭 축소가 왜 정확도를 깎는지, (2) 우리 구현이 문헌의 함정을 피하는지, (3) 실험에서 무엇을 재야 하는지를 정리한다.

## 1. 폭 축소(부분 모델 학습)의 정확도 대가 — 문헌
| 논문 | 방법 | 대가 (보고값) | 우리와의 관계 |
|---|---|---|---|
| HeteroFL (Diao·Ding·Tarokh, ICLR 2021) | 기기 능력별로 채널 앞부분만 잘라 쓰는 중첩 부분 모델, 서버는 학습된 채널만 평균 | CIFAR-10 ResNet-18: 전원 전폭 대비 폭 0.5·0.25 혼합 시 1~4%p 하락(구성에 따라). 작은 폭이 많을수록 큼 | 우리 `models.py slice_into/nested_average` 가 이 방식(중첩 슬라이스 + 학습된 채널만 표본 가중 평균) |
| FjORD (Horváth 외, NeurIPS 2021) | Ordered Dropout: 앞 채널부터 중요도 순, 기기별 최대 폭까지 | 낮은 폭 기기의 데이터가 뒤쪽 채널에 기여 못 함 → 이질 데이터에서 편향. 지식 증류로 완화 | 폭이 낮은 기기가 **항상 같은 기기**면 그 데이터 분포가 큰 채널에서 빠진다 — 우리 낙오자 2대가 그 경우 |
| FedRolex (Alam 외, NeurIPS 2022) | 창을 라운드마다 굴려(rolling) 모든 채널이 골고루 학습되게 | HeteroFL 대비 전역 모델 정확도 회복(CIFAR-10 +2~5%p 보고) | 우리 `_axis_index(off)` 에 창 오프셋이 있음(창 굴리기 지원) — 실험에서는 off=0 고정 |
| Slimmable / US-Nets (Yu 외, ICLR 2019 · ICCV 2019) | 한 모델을 여러 폭에서 동시에 학습 | **BN 통계는 폭마다 따로 둬야 한다**(switchable BN) — 폭이 다르면 채널 활성 분포가 달라 공유 BN 이 망가짐 | 우리 BN 이동 통계는 `AWARENET_BN=avg` 로 폭 간 평균 → 위험 요소. HeteroFL 의 sBN(이동 통계 안 씀, 추론 전 재추정)이 대안 = `AWARENET_BN=none` |
| Batch Renorm (Ioffe 2017) · GroupNorm (Wu·He, ECCV 2018) | 작은 배치에서 BN 통계가 흔들림 | 배치 8 이하에서 BN 정확도 급락, GN 은 배치 크기와 무관 | 즉시 내보내기(m=4, 조각 8장)의 정확도 하락(9/8 관찰)과 같은 기전 |
| FedCS (Nishio·Yonetani, ICC 2019) | 라운드 마감 T 안에 끝낼 수 있는 기기만 고름 | 느린 기기를 **배제**해 정확도·공정성 손해 | 우리는 배제 대신 폭을 깎는다 — "배제 < 폭 축소 < 망 교정" 순으로 대가가 작다는 게 주장 |
| Aergia (Cox 외, Middleware 2022) | 느린 기기의 연산을 빠른 기기에 넘김(부분 위탁) | 위탁 통신 비용, 데이터 이동 없음 | 우리 분할학습에서는 절단점 이동이 같은 역할 — 이번 실험 밖 |

## 2. 우리 구현의 정확도 위험 3가지 (실험 전 점검)
1. **BN 이동 통계의 폭 간 평균** — 위 Slimmable 지적. 폭 0.5 기기의 BN 통계(채널 앞 절반의 분포)와 전폭 기기의 통계가 섞인다. 조치: 주조건 실행에 `AWARENET_BN=none`(sBN)을 쓸지 결정해야 한다. 판단 근거: rw_long(400R) p0.5 결과가 avg 로 나왔고 79% 였음 — 나쁘지 않으므로 기본값(avg) 유지, 대신 팔 사이 비교는 같은 설정이면 공정. **결정: avg 유지, 문서에 명시.**
2. **낙오자 고정** — 폭이 깎이는 기기가 항상 c0·c1 이면 그 데이터가 뒤 채널에서 빠진다(FjORD). Dirichlet 비IID 이면 손해가 커진다. 조치: 원장의 dirichlet 값 확인, 결과 해석 시 "낙오자 데이터 편향" 항목 별도 표기. 창 굴리기(FedRolex)는 후속.
3. **즉시 내보내기의 작은 조각 BN** — m=4 는 조각 8장. 조치: h5acc path3m 결과로 대가 확정 후 m=2 또는 GN. 이번 3번의 `bothmpm` 팔은 정확도에서 이 대가가 섞여 나옴 — 표에서 `bothmp`(m=1)와 나란히 읽는다.

## 3. 실험에서 재는 것 (사전등록 §4 와 짝)
- 같은 D 에서 팔별 **폭 합/N** (얼마나 깎았나), **D 충족률** (맞췄나), **마지막 20R 정확도 평균** (대가), 라운드 시간.
- 가설: 폭만 ≈ 0.5 (전원) · 88% / 망만 1.0 · 75%(낙오자 미달) / 폭+엣지 0.78 (접속 병목까지 깎음) / **폭+엣지+분할 0.91 (낙오자만)** · 100%.
  정확도 순서 예측: 결합 ≥ 폭+엣지 > 폭만 (HeteroFL 의 "작은 폭 기기 비율이 클수록 손해"). 차이가 잡음(4~6%p)보다 작으면 폭 합으로 대리한다.

## 4. 즉시 내보내기(조각 8장)의 정확도 대책 — 후보와 절제 (2026-09-08 저녁, 3번 결과 뒤)
3번 결합 실험에서 즉시 내보내기 팔(m=4)은 시간·폭은 최선이었으나 24R 정확도가 10~18% (다른 팔 23~28%). 갱신 수식은 배치와 같으므로(1/m 누적, 배치 끝 1회 갱신 — 코드 재확인)
남는 원인은 배치 정규화가 조각 8장의 통계로 정규화·이동 통계 갱신을 한다는 것. 문헌의 대책과 우리 선택:
| 후보 | 원리 | 문헌 | 비용 | 우리 채택 |
|---|---|---|---|---|
| ① 조각을 2개로 (16장) | BN 통계 표본을 두 배로 | Ghost BN(Hoffer 2017)의 "가상 배치 ≥16" | 겹침 이득이 1−1/2 로 줄어 시간 이득 절반 | 팔 `path3m2` |
| ② GroupNorm | 표본이 아니라 채널 묶음으로 정규화 → 배치 크기 무관 | Wu·He 2018 (배치 2에서도 BN 32 와 대등) | ResNet-18 CIFAR 에서 BN 대비 −1~2%p 보고 | 팔 `path3m_gn` (+ 대조 `path3_gn`) |
| ③ Batch Renorm | 이동 통계로 보정해 작은 배치의 편향 완화 | Ioffe 2017 | 초기 라운드 이동 통계가 불안정 | 보류 |
| ④ 조각 간 통계 누적 (배치 안 Cross-Iteration BN) | 조각 i 는 조각 0..i 의 누적 통계로 정규화 | Yao 2020 (CBN) | 구현 복잡, 첫 조각은 여전히 8장 | 보류 |
| ⑤ 전체 배치 통계 선계산 | 배치 전체를 no-grad 로 한 번 지나 통계를 얻고 조각은 그 통계 사용 | — | 클라 연산 +1 순전파(≈+25%), 서버 쪽은 불가 | 보류 |
②는 폭 혼합(Slimmable 이 지적한 BN 통계 섞임)까지 같이 없애므로 이중 이득. 절제 조건 `h5xa`(h5x 4대·150/150, 60R, 2시드), 드라이버 `scripts/exp/run_micro_acc.sh`.
판정: m=4 GN 의 정확도가 m=1 BN 의 −3%p 안이면 ② 채택(라운드 시간은 m=4 BN 과 같아야 함). m=2 BN 이 그 안이면 ① 도 대안. GN 자체 대가는 `path3_gn` 로 분리.
