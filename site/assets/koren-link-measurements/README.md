# KOREN 동시 전송 원자료

보고서 그림 3의 기존 측정 원로그와 당시 측정 스크립트다. 새 실험을 수행하지 않았다.

- 동시 클라이언트 8, 16, 32, 48, 64, 96개
- 상·하행 각 4.2 MB, 4배치 × 3라운드, TCP 두 연결
- 접속·중계 제한을 4 Gbps 수준으로 높인 실제 HPC–KOREN VM 왕복 경로
- `batch_s_median`: 응용 텐서 왕복 완료 시간의 중앙값
- `batch`와 `burst`는 서로 다른 전송 패턴

그림은 `out/line_scale.jsonl`의 `n`, `pattern`, `batch_s_median`을 사용한다. 상세 JSON은 개별 클라이언트의 전송 구간과 시간을 포함한다. 이 수치는 종단 간 완료 지연이며 특정 코어 장비의 혼잡을 분리 측정한 값이 아니다. 후속 학습 실험은 관측한 병목을 장비 자원 안에서 반복 평가하도록 회선과 참여 규모를 축소했다.

각 파일은 원본 바이트 그대로이며 `manifest.json`에 SHA-256을 기록했다. 스크립트는 당시 실행 환경의 기록으로, 실제 실행에는 해당 연구망·호스트 권한과 의존 도구가 필요하다.
