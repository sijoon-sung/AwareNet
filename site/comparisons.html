기능을 켜고 끈 실제 학습

기존 CIFAR-10 실제 학습: 8클라이언트·24라운드·3시드·중계 125 Mbps×4·10초 목표 기반 제어. 시간·평균 폭은 초기 10라운드를 제외해 평균했다. 현재 λ 기반 정책 평가와 구분한다.

폭+경로와 폭+경로+분할은 9.22초와 9.29초로 비슷했다. 분할을 포함한 구성은 비슷한 시간에 평균 폭 0.813 대신 0.927을 유지했다. 이 표는 완료 시간과 모델 축소 정도를 비교한다. 분할 활성화는 연결 수도 바꾸므로 구성 전체의 비교이며, 조각 크기만의 효과는 별도 검증한다.

15개 학습 로그·30개 설정/프로파일·재집계 코드 ZIP · 시드별 결과·파일별 해시 JSON

압축을 푼 폴더에서 python reaggregate.py를 실행하면 표의 수치를 다시 계산한다. 새로 학습한 결과가 아니라 기존 기록을 재집계한 결과다.

표에서 원자료로

  • E1·E8: 32클라이언트 원로그 · 조건별 집계와 시드별 원파일 경로
  • E7·E8: 8클라이언트·200라운드 기록
  • E2: Jetson 연산·전력 원기록
  • E4: LoRA 분할 공동 학습·평가 기록
  • F1: Fashion-MNIST 조건·학습·예측 결과 ZIP · 집계 및 평가 범위
  • D1: CNN·LoRA 시연 원로그 · 원파일 해시
  • L1: LoRA 고정 배정 원로그 · 경로 제어 원로그
