AwareNet: joint width and permitted-path control for split federated learning

연구 요약

분할 연합학습은 기기의 연산을 서버로 옮기는 대신, 매 배치마다 활성값과 기울기를 교환한다. 이때 느린 학습이 기기의 계산에서 비롯되는지, 전송 경합에서 비롯되는지에 따라 필요한 제어가 다르다. AwareNet은 모델 폭이 결정하는 계산·전송 수요와 허용 경로의 처리 능력을 같은 완료 시간 모형으로 연결한다. 관리 가능한 기기·중계 호스트를 대상으로 구현하고, KOREN 실행 기록과 Jetson 연산 프로파일, 별도의 Linux 가상망 실험으로 적용 범위를 검토했다.

01

왜 두 제어를 함께 다루는가

일반적인 연합학습은 기기에서 여러 학습 단계를 수행한 뒤 모델 업데이트를 교환한다. 분할 연합학습(SFL)은 모델을 층 단위로 나누므로, 기기가 보낸 활성값에 대한 기울기가 돌아와야 해당 배치의 역전파를 마칠 수 있다. 메모리 부담을 줄이기 위해 도입한 분할이 통신 지연을 학습의 실행 경로 안으로 가져오는 것이다.

모델 폭 축소는 기기 계산량과 텐서 바이트를 줄이지만, 모델 용량과 파라미터의 학습 기회에도 영향을 준다. 반면 경로 변경은 모델을 유지한 채 전송 경합을 줄일 수 있으나, 경로들이 같은 접속 회선이나 큐를 공유하면 용량을 더하지 못한다. 두 제어를 독립적으로 수행하면 통신 문제에 대응해 불필요하게 모델을 줄이거나, 계산 병목에 효과가 없는 경로 변경을 반복할 수 있다.

연구 질문: 운영자가 사용할 수 있는 경로와 제한된 기기 자원 안에서, 폭 축소의 대가를 고려하면서 가장 늦은 참여자의 학습 완료 시간을 줄일 수 있는가?

먼저 학습을 마친 기기를 먼저 전송시키는 순서만으로는 라운드 단축을 보장할 수 없다. 본 설계는 활성값·기울기의 완료 지연과 공유 자원을 관측 대상으로 삼는다.

목적: 최대 라운드 완료 시간 + λ × 평균 폭 축소량을 최소화한다. 폭 보존 항은 학습 품질의 대리 비용이며 정확도 보장은 아니다.

변수의 의미

w는 채널·은닉 차원의 폭 비율이다. 층 분할 위치나 LoRA rank와 구별한다. S는 허용된 경유 종점의 배정이며, R은 공유 자원 아래의 유효 전송률이다. CNN의 바이트·계산 근사는 모델과 분할 위치에 따라 재측정해야 한다.

실행 구조

기기·전송 관측 → 라운드 수준 계획 → 폭·경유 종점·조각 할당 → TCP 전송·재조립의 순서로 동작한다. 패킷 처리는 커널과 고정 전송 코드가 담당한다. 제어기의 매 패킷 AI 추론은 구현하지 않았다.

04

기여의 위치와 남은 검증

폭 기반 이질적 학습은 FjORD·FedRolex에, 자원 적응형 분할 학습은 AdaptSFL·SuperSFL에 관련 연구가 있다. 통신·연산의 결합 최적화 역시 선행연구가 있으므로 이 결합 자체를 최초성으로 주장하지 않는다.

현재 기여는 기관 간 제어 권한과 공유 병목을 전제로 폭·허용 경로를 연결한 시스템 구성, 그리고 실장비·연구망 실행에서 얻은 원자료와 실패 조건을 함께 추적할 수 있는 검증에 있다. 네트워크 개입이 동일 학습 품질에서 시간을 줄이는지는 같은 출구 수·학습량을 유지한 절제 실험과 동일 정확도 도달 시간 평가로 확인해야 한다.

KOREN의 역할

기관이 운영하는 원격 VM과 HPC 사이에서 실제 TCP 전송, 분할 학습 및 호스트 수준 제어를 시험한 연구망이다. 공중 무선망이나 KOREN 코어를 제어하는 서비스 배치를 주장하지 않는다.

축소와 재현의 위치

8프로세스 축소 실행과 32프로세스 실행은 별도 조건이다. 과거 Jetson·KOREN 수치를 주입한 재현은 가설 검토에 사용하며, 새 하드웨어 측정으로 표기하지 않는다. E7: 축소 조건·재현 자료

주요 선행연구: FjORD · FedRolex · AdaptSFL · SuperSFL · 통신·연산·분할 결합 최적화. 개별 비교와 판본은 보고서 참고문헌을 따른다.
