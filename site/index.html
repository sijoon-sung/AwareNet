01

폭을 줄이기 전에, 경로로 해결할 수 있는가

의료·제조처럼 데이터를 기관 밖으로 모으기 어려운 환경에서 연합학습은 데이터를 현장에 보관하며 공동 모델을 학습하는 방법이다. 전체 모델의 연산·메모리 부담을 줄이기 위해 분할 연합학습(SFL)은 모델을 클라이언트와 서버에 나눈다.

SFL은 배치마다 활성값과 기울기를 교환한다. 동기식 학습에서는 연산 지연과 네트워크 병목 모두 스트래글러를 만들며, 가장 늦게 완료되는 클라이언트가 라운드 시간을 결정한다. 두 병목에 필요한 조치는 다르다.

폭 축소는 계산량과 전송량을 함께 줄이며, 학습에 사용하는 모델 용량도 줄인다. 경로 변경은 모델을 유지한 채 중계 경합을 분산한다. 이를 따로 적용하면 우회로 해결할 지연에 폭을 줄이거나, 계산이 느린 클라이언트의 경로만 바꾸게 된다. AwareNet은 공유 회선 아래의 처리 능력을 평가한 뒤, 남은 지연에 폭 제어를 적용한다.

경로 재배정으로 모델 폭을 유지할 수 있는가? 남은 지연을 줄이려면 어느 클라이언트의 폭을 얼마나 조정해야 하는가?
MODEL

폭 축소의 비용을 고려하고, 학습 방법은 교체한다

초기 FjORD 계열 구현은 앞쪽 채널을 선택해 작은 모델을 학습했다. 일부 채널에 학습이 집중되는 문제를 보완하려고 FedRolex식 채널 순환 선택을 추가했다. CNN에서 폭은 채널 수이며, 순환 선택은 그중 어떤 채널을 학습할지 바꾼다.

CNN은 계산량과 활성값 크기의 관계를 측정하기 위한 평가 모델이다. AwareNet은 사용할 모델 크기와 전송 경로를 정하고, 학습 모듈은 실제 서브모델 추출과 집계를 담당한다. 다른 알고리즘에도 모델별 계산·전송 프로파일과 집계 규칙을 연결할 수 있다.

고정·순환 선택을 검토한 기록과 별도 300라운드 실행은 E9에 보존했다. 아래 24·200라운드 수치는 해당 결합 실행의 결과이며, 두 알고리즘의 동일 조건 우열 비교와 구분한다.

채널 수를 바꿔 줄어드는 계산 시간과 경로를 바꿔 줄어드는 전송 시간을 초 단위로 비교한다. w는 CNN의 폭 비율이며 b×w는 채널 감소에 따른 전송량이다. λ(람다)는 모델 축소에 부여할 비용의 크기를 정하는 설정값이다. 크게 잡으면 폭을 더 유지하고, 작게 잡으면 시간 단축을 위해 더 적극적으로 줄인다. 시간과 더해 비교하므로 단위는 초다.

1. 현재 폭으로 경로 평가

허용된 중계 서버 조합을 최대 지연과 평균 지연의 합으로 비교한다. 공유 자원을 지나는 흐름은 용량을 나누어 사용한다. 경로 전환의 이득을 확인하고 라운드별 이동 수를 제한한다.

2. 남은 지연에 폭 제어

가장 느린 클라이언트들의 폭을 한 단계 낮춰 보는 후보를 만든다. 예상 시간 감소의 90%가 λ × 평균 폭 비율 감소량보다 크면 채택한다. 예를 들어 λ=70에서 평균 채널 비율을 0.1 줄이면 축소 비용은 7초다. 10% 보정 후의 예상 시간 이득이 7초를 넘어야 선택한다.

결정된 연결별 예상 전송률에 따라 텐서 조각을 배분하고, 수신 측은 조각이 모두 도착하면 학습 계산에 전달한다. 관측 용량은 경로 이동에, 설정 용량과 공유 배정은 조각 비율에 사용한다. 전송·환경 설정의 상세 구현은 구현 자료 E6에 수록했다.

KOREN

실망에서 관찰한 병목을 축소 환경에서 검증한다

변동 요인을 통제하고 실제 전송 비용을 측정하는 연구 환경

KOREN 연구망은 원격 자원을 연결해 실제 학습 트래픽의 전송 비용을 측정할 기반을 제공했다. 원격 VM 두 대와 HPC를 연결해 실제 소켓·큐·텐서 변환을 포함한 학습 지연을 측정했다. 참여 수와 중계 용량을 바꾸면서 연산과 통신 병목의 상호작용을 확인할 수 있었다.

KOREN을 경유하는 실제 텐서 전송에서 동시 클라이언트 수가 늘면 완료 지연이 커지는 것을 확인했다. 별도의 속도 제한 없이 측정한 배치 왕복 중앙값은 8개에서 0.41초, 32개에서 2.18초였다. 양호한 연구망에서도 학습 트래픽이 한꺼번에 모이면 종단 간 전송 경합이 생긴다.

이 관측을 바탕으로 회선에 속도 제한과 변동을 적용해 혼잡을 반복 평가했다. CPU·메모리 한도 때문에 32개 논리 클라이언트로 단기 제어를, 8개로 장기 학습을 수행했다. 대역폭 0.1배 조정과 참여 수 축소는 서로 다른 조건이므로 실행별로 제시한다.

T-SDN·L2VPN을 활용한 후속 확장

현재는 클라이언트 프로그램에서 중계 서버와 전송 비율을 선택한다. KOREN 내부 스위치·라우터의 설정은 변경하지 않았다. 향후 허용 구간의 SDN 스위치 제어와 KOREN T-SDN·L2VPN 연계를 별도로 검증한다. L2VPN으로 기관 간 논리망을 구성하고, T-SDN으로 제공받는 경로·회선 자원을 스케줄러에 반영한다. 확보한 전송 여유를 스케줄러에 반영하면 모델 폭을 더 오래 유지할 가능성이 있다. 이번 실험에는 두 서비스를 적용하지 않았으며, 성능은 운영기관과 협의한 대역폭·공유 구간 조건에서 평가한다. NIA KOREN 이용안내서, 6–9쪽 · 보고서 16쪽

연구망과 실제 장비에서 확인한 실행 조건

LoRA가 등장하는 이유: 언어모델의 분할 학습을 확인하기 위해

CNN 실험에서는 폭·경로 스케줄러를 평가했다. 이어 언어모델에서도 자원이 제한된 클라이언트와 서버가 함께 학습하고 결과를 집계할 수 있는지 확인했다. 이 보조 실험은 학습 파라미터를 줄이는 방법으로 LoRA(Low-Rank Adaptation)를 사용했다.

LoRA는 원래 가중치를 고정하고 추가한 저랭크 행렬을 학습한다. CNN의 채널 수와 LoRA 랭크 r은 다른 변수다. CNN 채널 축소는 활성값 크기를 줄이지만, LoRA 랭크만 바꾸면 분할 활성값의 은닉 차원은 유지된다. 랭크는 학습 파라미터와 어댑터 집계량에 영향을 준다.

모델 폭 축소와 LoRA를 함께 쓰는 확장도 가능하다. SliceGPT는 언어모델의 은닉 차원을 줄인 뒤 LoRA로 추가 학습한다. AwareNet에서는 고정 축소 모델의 품질과 분할 전송부터 검증하고, 이후 폭 전환과 경로 선택을 연결하는 후속 설계로 정리했다.

05

기대 효과: 병원 등 여러 기관이 함께 전역 모델을 개선하는 환경

병원처럼 데이터를 한곳에 모으기 어려운 기관들이 영상 분류 모델을 함께 학습하는 환경을 생각할 수 있다. 클라이언트의 계산 능력과 통신 상태에 맞춘 스케줄링으로 공동 학습의 대기를 줄이고, 여러 기관의 데이터가 반영된 전역 모델(global model)을 지속적으로 개선할 기반을 마련하는 것이 기대 효과다.

학습에 맞춘 네트워크 운용

클라이언트 계산이 오래 걸리면 채널 수를 줄이는 방안을 평가한다. 중계 구간이 혼잡하고 다른 경로에 여유가 있으면 모델을 유지하며 전송을 분산한다. 공유 회선 용량과 모델 품질을 함께 고려한다.

현장 적용의 평가 기준

중계 사용 권한과 관측값 수집을 갖추고, 활성값·기울기의 정보 노출 위험을 별도로 검토한다. 효과는 목표 성능에 도달하는 시간과 기관별 모델 성능으로 평가한다. 현재 실측은 KOREN·CIFAR-10과 Jetson·LoRA 실행을 대상으로 한다.

기관 간 연합학습 사례: EXAM, Nature Medicine (2021)

기여와 후속 평가

핵심은 경로 조정 후의 예상 완료 시간으로 모델 축소의 필요성을 판단하는 스케줄링 방식이다. 공유 접속·중계 용량을 반영한 시간 감소가 폭 축소 비용보다 클 때 축소를 채택한다. 관측 용량이 바뀐 라운드에는 폭을 유지해 두 제어의 과도한 동시 반응을 억제한다. KOREN의 시간 측정과 별도 장기 학습의 정확도를 함께 제시해 설정별 효과를 비교했다. FjORD·FedRolex의 서브모델 학습, AdaptSFL·SuperSFL의 자원 적응형 SFL 연구를 토대로, 고정된 층 분할에서 폭과 중계 배정을 운용하는 문제에 집중했다.

다음 평가는 같은 연결 수를 유지한 정책 비교, 목표 정확도 도달 시간, 독립 시드 확대에 집중한다. 현재 제어 범위는 클라이언트 프로그램과 허용된 중계 서버이며, 기관 간 네트워크 규칙의 위임·인증과 OS-Ken 스위치 연동은 후속 통합 대상이다.

주요 선행연구: FjORD · FedRolex · AdaptSFL · SuperSFL. 개별 비교와 판본은 보고서 참고문헌을 따른다.
